# Roadmap

The source of truth for the roadmap is the public [GitHub Project board](https://github.com/orgs/getrunbase/projects). This file only explains how it works, so it never goes out of date.

A readable version is published on the website: [getrunbase.com/roadmap](https://getrunbase.com/roadmap).

## Columns

| Column          | Meaning                                                                                                                                           |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Ideas**       | Proposals under discussion, usually from [Discussions, Ideas](https://github.com/getrunbase/runbase/discussions/categories/ideas). No commitment. |
| **Planned**     | Accepted work, labelled `roadmap` and `status: accepted`. Contributions are welcome: comment on the issue before you start.                       |
| **In progress** | Someone is working on it. A linked pull request or a draft is expected.                                                                           |
| **Shipped**     | Released. See the [CHANGELOG](CHANGELOG.md) and the [releases](https://github.com/getrunbase/runbase/releases).                                   |

## How an item moves

1. An idea is posted in Discussions and lands in **Ideas**.
2. Large changes go through an RFC (see [GOVERNANCE.md](GOVERNANCE.md)).
3. A maintainer accepts it: the issue gets the `roadmap` and `status: accepted` labels and moves to **Planned**.
4. It moves to **In progress** when work starts, then to **Shipped** when it is released.

Upvote ideas and issues with a thumbs-up reaction: it helps us prioritize.
