# Getting help

Runbase has no Discord or chat server. All support happens on GitHub, in public, so answers help the next person.

1. **Read the docs**: [getrunbase.com/docs](https://getrunbase.com/docs) covers installation, self-hosting, the MCP server and connectors.
2. **Ask a question**: [GitHub Discussions, Q&A category](https://github.com/getrunbase/runbase/discussions/categories/q-a). Search first: your question may already have an answer.
3. **Suggest an idea**: [GitHub Discussions, Ideas category](https://github.com/getrunbase/runbase/discussions/categories/ideas).
4. **Report a bug**: [open an issue](https://github.com/getrunbase/runbase/issues/new/choose) with the bug report form. Issues are for confirmed bugs and accepted work only.
5. **Report a security vulnerability**: follow [SECURITY.md](SECURITY.md). Never open a public issue or discussion for a vulnerability.

Maintainers answer on a best-effort basis. See [GOVERNANCE.md](GOVERNANCE.md) for response time goals.
