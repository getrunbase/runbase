# Maintainers

Runbase is maintained by MENTIONABLE SAS. Maintainers review and merge pull requests, triage issues and decide on RFCs (see [GOVERNANCE.md](GOVERNANCE.md)).

| Name                            | GitHub                                           | Area                    |
| ------------------------------- | ------------------------------------------------ | ----------------------- |
| MENTIONABLE SAS (project owner) | [@AlexRastello](https://github.com/AlexRastello) | Project lead, all areas |

## Becoming a maintainer

Maintainers are appointed by the project owner. We look for contributors with a track record of quality pull requests (for example, five or more merged), helpful reviews and triage, and respect for the [Code of Conduct](CODE_OF_CONDUCT.md). Triagers are usually invited first.
