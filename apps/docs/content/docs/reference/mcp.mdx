The MCP server exposes 128 tools at `/api/mcp`. Every tool except `workspaces.list` and `workspaces.use` accepts an optional `workspace` parameter (id or name); without it, the active workspace is used.

## api_keys

### api_keys.create

Creates an API key (admin scope). The plaintext key is returned only once. The key only sees its `workspaceIds`. Optional restrictions: `tools` (allowed MCP tool names, e.g. ["records.search", "records.upsert"]; the others are hidden) and `objects` (visible object slugs: other objects and their records stay invisible, query.sql unavailable). Absent = everything.

### webhooks.create

Creates a public endpoint POST /api/hooks/&lt;id&gt; (`path`): signature verified with the secret `secretName` (secrets.set), then event `eventType` pushed (workflow trigger), deduplicated by the external id (`config.idPath`, default `id`). `config.dedupe`: `id` (default: a resend of the same id is dropped, response duplicate: true, no workflow), `id+hash` (dropped only if the item content is identical: an enriched resend of the same id creates a new event and starts the workflow), `none` (every call creates an event). Unique name per workspace. Formats: `stripe`, `standard` (Standard Webhooks/Svix, id = webhook-id header), `hmac` (header, algorithm sha256|sha1|sha512, encoding hex|base64, prefix e.g. `sha256=`, timestampHeader + template `\{timestamp\}.\{body\}`, idHeader; headerFormat `kv` reads a `t=&lt;unix&gt;,v1=&lt;sig&gt;[,v1=…]` header value with timestampKey (default `t`) and signatureKey (default `v1`, any listed signature matches), signedPayload default `\{t\}.\{body\}`, toleranceSec default 300; secretEncoding raw (default) | base64 | whsec (`whsec_&lt;base64&gt;` decoded)). `stripe` = hmac kv on `stripe-signature`. Outreach-like: \{ format: 'hmac', header: 'X-Outreach-Signature', headerFormat: 'kv', signedPayload: '\{t\}.\{body\}' \}. Cal.com: hmac header `x-cal-signature-256`. Batches: `config.splitPath` (e.g. `events`) or a root array give one event per item, `idPath` relative to the item. `config.storeSample: false`: no sample stored. Test URL `testPath` (/api/hooks/&lt;id&gt;/test): signature verified and sample saved, no event or workflow started (to listen to a provider's next call and write the mapping).

### workflows.create

Creates a workflow (draft status, version 1). Definition: trigger, steps, next, entry. next[step][branch] = a step id or an array of ids (steps started in parallel). entry = steps started by the trigger (absent: the first step). Event trigger: \{"type": "trigger.event", "event": "&lt;event type&gt;"\} (`eventType` accepted). Without a join, two paths that converge run the common step twice; step `join: true`: waits for all paths and runs only once. Step options (next to input): `timeout` ("30s", "5m"; default 5m, network calls included) and `retry` \{ attempts (1-10, default 3), backoff ("1s", doubled on each attempt), continueOnFail (after the last failure, follows the error branch if connected, otherwise the first) \}. `timeout` at definition level: global run deadline ("2h"). human.approve accepts input.timeout ("2d"): without a decision, expired branch if connected, otherwise failure. `concurrencyKey` at definition level: template rendered at run start (e.g. "\{\{record.company_id\}\}"): at most one active run per key value, later runs wait their turn (creation order), nothing is dropped. condition and switch read the record (object, recordId, condition / field) or, in value mode, any run value: condition \{ left: "\{\{steps.x.output.y\}\}", op, right \}, switch \{ value: "\{\{steps.x.output.y\}\}", cases: [\{ id, label, op, value \}] \} (filter operators: eq, neq, gt, in, contains, is_empty…). Input variables: \{\{record.…\}\}, \{\{event.…\}\} (\{\{event.recordId\}\} = record linked to the triggering event), \{\{steps.&lt;id&gt;.output.…\}\}, \{\{now\}\}, \{\{today\}\}, \{\{run.id\}\}, \{\{run.test\}\} (true in a test run), \{\{workflow.id\}\} (an unknown variable is reported by workflows.validate); in loop.do: \{\{item\}\}, \{\{index\}\} and all run variables (fn.\* and raw-input blocks allowed). Triggers: trigger.schedule \{ cron, object? (without object: a single run), filter?, timezone? (IANA) \}; trigger.run_failed \{ workflow? \}: error workflow started when a run fails (\{\{event.runId\}\}, \{\{event.workflowName\}\}, \{\{event.error\}\}). Sub-workflow: block workflow.run \{ workflow (id or name), recordId?, event?, wait (default true: waits, ok/error branches, output = last output) \}, max depth 5. `pins` \{ stepId: \{ output, branch? \} \}: pinned outputs replayed by dry_run and test_step.
