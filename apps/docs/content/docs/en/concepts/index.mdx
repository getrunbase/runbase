---
title: Concepts
description: The building blocks of Runbase and how they fit together.
---

| Concept | What it is |
| --- | --- |
| [Workspaces](/docs/concepts/workspaces) | Isolated spaces inside an organization. Unlimited and free. |
| [Data](/docs/concepts/data) | Databases, objects (typed schemas) and records. |
| [Events](/docs/concepts/events) | Timestamped facts, linked to a record or not. |
| [Webhooks](/docs/concepts/webhooks) | Public URLs that turn inbound calls into events and records. |
| [Functions](/docs/concepts/functions) | Versioned JavaScript code run in a sandbox. |
| [Workflows](/docs/concepts/workflows) | Triggers plus a graph of nodes, run durably. |
| [Interfaces](/docs/concepts/interfaces) | Pages, dashboards and code components. |
