---
title: Introduction
description: Runbase is a data, automation and interface platform that AI agents build on.
---

Runbase gives an AI agent everything it needs to build a business tool end to end:
typed data, events, inbound webhooks, sandboxed functions, workflows and
interfaces. The agent drives it through [MCP](/docs/reference/mcp); people use the
web app; programs use the [REST API](/docs/reference/api).

- New here? Start with the [quickstart](/docs/quickstart).
- Running your own instance? Read [self-hosting](/docs/self-hosting).
- Want the mental model? Read the [concepts](/docs/concepts).
- Extending Runbase? See [writing a connector](/docs/guides/connectors) and the
  [template format](/docs/guides/templates).
