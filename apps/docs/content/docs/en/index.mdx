title: Introduction
description: Runbase lets your AI agent build and run the tools your team rents today, open source and self-hostable.
---

Stop renting tools that almost fit. With Runbase, your agent builds the CRM,
workflow or dashboard you need and keeps it running: typed data, events, inbound webhooks, sandboxed functions, workflows and
interfaces. Any agent drives it through [MCP](/docs/reference/mcp); people use the
web app; programs use the [REST API](/docs/reference/api). Every change is validated and
versioned before it goes live, and you can self-host it or leave anytime.

- New here? Start with the [quickstart](/docs/quickstart).
- Running your own instance? Read [self-hosting](/docs/self-hosting).
- Want the mental model? Read the [concepts](/docs/concepts).
- Extending Runbase? See [writing a connector](/docs/guides/connectors) and the
  [template format](/docs/guides/templates).
