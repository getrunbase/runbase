## errors.list

Lists the workspace errors (ingest, workflow, function = function call from a page, mcp = failing MCP tool, component = code component failing in a user's browser; payload \{page, block\}), most recent first. Filters: source, status, run, workflow, record, period (from/to ISO). Returns \{ items, hasMore, nextCursor \}: pass nextCursor back as cursor for the next page.

| Name         | Type    | Required | Description                                                                           |
| ------------ | ------- | -------- | ------------------------------------------------------------------------------------- |
| `source`     | string  | no       | One of: `ingest`, `workflow`, `function`, `mcp`, `component`.                         |
| `status`     | string  | no       | One of: `open`, `resolved`.                                                           |
| `runId`      | string  | no       |                                                                                       |
| `workflowId` | string  | no       |                                                                                       |
| `recordId`   | string  | no       |                                                                                       |
| `from`       | string  | no       |                                                                                       |
| `to`         | string  | no       |                                                                                       |
| `group`      | boolean | no       | One item per fingerprint (same normalized message): the latest, with count and lastAt |
| `cursor`     | string  | no       |                                                                                       |
| `limit`      | integer | no       | Default 50                                                                            |
| `workspace`  | string  | no       | Workspace id or name (default: active workspace)                                      |
