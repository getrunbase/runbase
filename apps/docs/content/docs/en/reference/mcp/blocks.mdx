## blocks.list

Catalog of workflow blocks (kind: "block"): type, branches, input and output JSON schemas, including the workspace functions as fn.&lt;name&gt;. Also lists the triggers (kind: "trigger", for definition.trigger) with their parameters as inputSchema. Deprecated blocks are omitted (they still run in existing workflows).

| Name        | Type   | Required | Description                                      |
| ----------- | ------ | -------- | ------------------------------------------------ |
| `workspace` | string | no       | Workspace id or name (default: active workspace) |
