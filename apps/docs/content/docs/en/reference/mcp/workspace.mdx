## workspace.describe

The whole workspace in one call: databases &gt; objects (fields, record count), workflows (trigger, steps, status), functions (schemas, permissions, limits), webhooks, pages, secret names, SQL views readable by query.sql (name, columns, types), counters (records, events, active runs, open errors). Call it first to discover a workspace.

| Name        | Type   | Required | Description                                      |
| ----------- | ------ | -------- | ------------------------------------------------ |
| `workspace` | string | no       | Workspace id or name (default: active workspace) |

## workspace.purge_test

Deletes test data (created with test: true): records (trash then purge, relations removed), finished events and runs (a still-active run is kept: runs.cancel first). dryRun: true returns the counts without deleting anything; otherwise confirm: true required. hasMore: call again for the next batch.

| Name        | Type    | Required | Description                                      |
| ----------- | ------- | -------- | ------------------------------------------------ |
| `dryRun`    | boolean | no       |                                                  |
| `confirm`   | boolean | no       |                                                  |
| `workspace` | string  | no       | Workspace id or name (default: active workspace) |
