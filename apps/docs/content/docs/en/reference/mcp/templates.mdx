## templates.submit

Submits a template to the public Runbase catalog. Automatic validation first: description of at least 300 words with the sections ## Who it's for, ## The problem, ## What it does, ## Setup; valid runbase-template.json manifest (get it with template.export); author profile (pass `author` for a first template). Rejected: one clear error per problem. Accepted: opens a pull request for human review and returns its URL; the template is published on merge. No payment involved.

| Name             | Type   | Required | Description                                                                                                 |
| ---------------- | ------ | -------- | ----------------------------------------------------------------------------------------------------------- |
| `slug`           | string | yes      | Template slug (folder name), e.g. crm-light                                                                 |
| `name`           | string | yes      |                                                                                                             |
| `categories`     | array  | yes      |                                                                                                             |
| `githubUsername` | string | yes      | Creator's GitHub login (authorId)                                                                           |
| `description`    | string | yes      | Markdown, at least 300 words, with the sections: ## Who it's for, ## The problem, ## What it does, ## Setup |
| `manifest`       | object | yes      | The runbase-template.json manifest (template.export)                                                        |
| `author`         | object | no       | Creator profile, required for a first template                                                              |
| `workspace`      | string | no       | Workspace id or name (default: active workspace)                                                            |
