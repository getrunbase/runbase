## objects.create

Creates an object. Field types: text, number, bool, date, select, multi_select, email, url, json, ref, refs, currency \{ currency?: 'EUR' \}, percent (12.5 = 12.5%), phone, rating \{ scale?: 5 \}, user, file (list of \{ key, name, size, type \} returned by files.upload). Computed (input value ignored): formula \{ formula: 'amount _ qty', result?: text|number|bool|date \} recomputed on every write (operators + - _ / % = != &lt; &gt; and or not, functions if, concat, round, abs, min, max, upper, lower, len, coalesce, empty, today, days_between); lookup \{ through, field \} and rollup \{ through, op: count|sum|avg|min|max, field? \} computed on read (through = ref/refs field, or slug of an object that points to this one); created_at, updated_at, created_by, autonumber. Per-field validation: required, pattern (regex), minLength, maxLength, min, max; default = value set on creation. `unique: true` (text, email, url, number, phone): unique value in the database, even under concurrent writes (two simultaneous webhooks for the same email -&gt; a single record, or a conflict error without match); serves as the `match` key for records.upsert. Email compared in lowercase.
