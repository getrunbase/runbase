## 1. Start an instance

You need Docker with the Compose plugin and `openssl`.

```sh
git clone https://github.com/getrunbase/runbase runbase && cd runbase
./setup.sh
docker compose -f docker-compose.selfhost.yml up -d --wait
docker compose -f docker-compose.selfhost.yml exec worker pnpm admin:create you@example.com
```

Open `http://localhost:3000/login` and ask for a sign-in link. Without email
settings, the link is printed in the web logs:

```sh
docker compose -f docker-compose.selfhost.yml logs web | grep email:console
```

See [self-hosting](/docs/self-hosting) for HTTPS, backups and upgrades.

## 2. Connect an agent

The MCP endpoint is `http://localhost:3000/api/mcp`. Clients sign in through the browser
(OAuth). Pick yours:

- **Claude Code**: `claude mcp add --transport http runbase http://localhost:3000/api/mcp`, then
  `/mcp` in Claude Code to sign in.
- **Claude Desktop / claude.ai**: Settings → Connectors → Add custom
  connector, paste the URL.
- **ChatGPT** (web): chatgpt.com/plugins → **+** → **Add custom MCP server**,
  paste the URL, pick OAuth, accept the warning, **Create as a plugin**. Type
  `@` in a chat to use it. Write tools need a Business or Enterprise/Edu plan
  (Pro is read only).
- **Gemini CLI**: `gemini mcp add --transport http runbase http://localhost:3000/api/mcp`, then
  `/mcp auth runbase`. The Gemini web app (Settings → Connected Apps → Add a
  custom app) has limited availability.
- **Cursor**: add `{"mcpServers":{"runbase":{"url":"http://localhost:3000/api/mcp"}}}` to
  `~/.cursor/mcp.json`. Cursor asks you to sign in on first use.
- **Codex**: `codex mcp add runbase --url http://localhost:3000/api/mcp`, then
  `codex mcp login runbase`.
- **Other MCP clients**: use the URL (Streamable HTTP, OAuth), or create an
  API key in **Settings → API keys** and send it as
  `Authorization: Bearer <key>`.

## 3. Build something

Ask the agent, for example:

> Build a small CRM: companies and contacts, a lead score, a workflow that
> scores new contacts, and a pipeline page.

The agent typically calls `workspace.describe`, then `databases.create`,
`objects.create`, `records.upsert_batch` (with `test: true` for sample data),
`workflows.create` and `page.create`. Every tool is listed in the
[MCP reference](/docs/reference/mcp).

## 4. Clean up test data

`workspace.purge_test` with `{ "dryRun": true }`, then `{ "confirm": true }`,
deletes the test records, events and runs.
