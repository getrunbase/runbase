## members.invite

Invite une personne dans l'organisation par e-mail (périmètre admin). L'invitation reste en attente, sans aucun accès, jusqu'à ce que la personne invitée l'accepte (e-mail envoyé avec le lien). Rôles : admin (gère tout), member (crée et modifie), viewer (lecture seule), end_user (ouvre uniquement des pages, pas de MCP). Par défaut : member.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `email`     | string | oui    |                                                                                    |
| `role`      | string | non    | Valeurs possibles : `admin`, `member`, `viewer`, `end_user`.                       |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## members.list

Liste les membres de l'organisation et les invitations en attente (pending: true) : id, nom, e-mail, rôle.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## members.remove

Retire un membre de l'organisation ou annule une invitation (périmètre admin). Le propriétaire ne peut pas être retiré.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `id`        | string | oui    |                                                                                    |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## members.set_role

Change le rôle d'un membre (id issu de members.list, périmètre admin). Le rôle du propriétaire ne change pas.

| `role`      | string | oui    | Valeurs possibles : `admin`, `member`, `viewer`, `end_user`.                       |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |
