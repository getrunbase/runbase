## connections.delete

Déconnecte un compte OAuth (id issu de connections.list) et révoque son accès chez le fournisseur. Les workflows qui l'utilisent échouent jusqu'à sa reconnexion.

| Nom         | Type   | Requis | Description                                           |
| ----------- | ------ | ------ | ----------------------------------------------------- |
| `id`        | string | oui    |                                                       |
| `workspace` | string | non    | Id ou nom du workspace (par défaut : workspace actif) |

## connections.list

Liste les connexions OAuth du workspace (fournisseur, nom, email du compte). Passez le nom dans l'entrée `connection` d'un nœud de connecteur quand le workspace a plusieurs comptes chez ce fournisseur. L'utilisateur connecte de nouveaux comptes depuis l'éditeur de workflow ou Paramètres › Connexions.

| Nom         | Type   | Requis | Description                                           |
| ----------- | ------ | ------ | ----------------------------------------------------- |
| `workspace` | string | non    | Id ou nom du workspace (par défaut : workspace actif) |

## connections.providers

Liste les fournisseurs OAuth des connecteurs installés : scopes, types de nœuds et présence d'un client OAuth configuré.

| Nom         | Type   | Requis | Description                                           |
| ----------- | ------ | ------ | ----------------------------------------------------- |
| `workspace` | string | non    | Id ou nom du workspace (par défaut : workspace actif) |
