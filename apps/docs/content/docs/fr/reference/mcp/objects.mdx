## objects.create

Crée un objet. Types de champs : text, number, bool, date, select, multi_select, email, url, json, ref, refs, currency \{ currency?: 'EUR' \}, percent (12.5 = 12,5 %), phone, rating \{ scale?: 5 \}, user, file (liste de \{ key, name, size, type \} renvoyés par files.upload). Calculés (valeur saisie ignorée) : formula \{ formula: 'amount _ qty', result?: text|number|bool|date \} recalculée à chaque écriture (opérateurs + - _ / % = != &lt; &gt; and or not, fonctions if, concat, round, abs, min, max, upper, lower, len, coalesce, empty, today, days_between) ; lookup \{ through, field \} et rollup \{ through, op: count|sum|avg|min|max, field? \} calculés à la lecture (through = champ ref/refs, ou slug d'un objet qui pointe vers celui-ci) ; created_at, updated_at, created_by, autonumber. Validation par champ : required, pattern (regex), minLength, maxLength, min, max ; default = valeur définie à la création. `unique: true` (text, email, url, number, phone) : valeur unique dans la base, même en cas d'écritures concurrentes (deux webhooks simultanés pour le même e-mail -&gt; un seul enregistrement, ou une erreur de conflit sans match) ; sert de clé `match` pour records.upsert. E-mail comparé en minuscules.

## objects.export

Exporte tous les enregistrements d'un objet, 1000 par page, sans limite totale. format csv (par défaut, en-tête sur la 1re page) ou json. Renvoie \{ csv | rows, next \} ; page suivante avec after = next, jusqu'à next = null.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `object`    | string | oui    | Slug ou identifiant (uuid) de l'objet                                              |
| `format`    | string | non    | Valeurs possibles : `csv`, `json`.                                                 |
| `after`     | string | non    |                                                                                    |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## objects.migrate

Fait évoluer le schéma d'un objet en conservant les données. op : rename \{ field, to, label? \} (valeurs copiées) ; change_type \{ field, type, options?, object?, dropInvalid? \} (valeurs converties ; refusé s'il reste des valeurs invalides, sauf si dropInvalid les vide) ; add \{ field: definition, default? \} (valeur par défaut écrite dans les enregistrements existants, obligatoire si le champ est requis) ; require \{ field, default? \} (valeur par défaut pour les enregistrements vides) ; delete \{ field \} (supprimé des enregistrements). Appelez toujours d'abord avec dryRun: true : renvoie \{ records, touched, invalid, samples \}.
