## feedback.send

Envoie un retour à l'équipe Runbase, qui le lit pour améliorer le produit. Appelez-le sans attendre qu'on vous le demande dès que : un outil se comporte mal ou renvoie une erreur inattendue (`bug`), une fonctionnalité manque et vous devez la contourner ou abandonner (`limit`), vous voyez une amélioration utile (`idea`), ou pour décrire ce que l'utilisateur cherchait à faire (`usage`). Soyez factuel : ce que vous tentiez, l'appel exact, le résultat obtenu par rapport au résultat attendu, le contournement. Jamais de secret ni de donnée personnelle.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `kind`      | string | oui    | Valeurs possibles : `bug`, `limit`, `idea`, `usage`.                               |
| `title`     | string | oui    | Résumé en une ligne                                                                |
| `details`   | string | oui    | Contexte, étapes, résultat attendu et obtenu, contournement                        |
| `tool`      | string | non    | Outil concerné                                                                     |
| `context`   | object | non    | Données utiles : arguments, message d'erreur, identifiants                         |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |
