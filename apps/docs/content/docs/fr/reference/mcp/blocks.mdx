## blocks.list

Catalogue des blocs de workflow (kind : "block") : type, branches, schémas JSON d'entrée et de sortie, y compris les fonctions de l'espace de travail sous la forme fn.&lt;name&gt;. Liste aussi les déclencheurs (kind : "trigger", pour definition.trigger) avec leurs paramètres dans inputSchema. Les blocs obsolètes sont omis (ils tournent toujours dans les workflows existants).

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |
