## workflows.create

Crée un workflow (statut brouillon, version 1). Définition : trigger, steps, next, entry. next[step][branch] = un identifiant d'étape ou un tableau d'identifiants (étapes démarrées en parallèle). entry = étapes démarrées par le déclencheur (absent : la première étape). Déclencheur sur événement : \{"type": "trigger.event", "event": "&lt;event type&gt;"\} (`eventType` accepté). Sans jointure, deux chemins qui convergent exécutent deux fois l'étape commune ; étape `join: true` : attend tous les chemins et ne s'exécute qu'une fois. Options d'étape (à côté de input) : `timeout` ("30s", "5m" ; 5m par défaut, appels réseau compris) et `retry` \{ attempts (1-10, 3 par défaut), backoff ("1s", doublé à chaque tentative), continueOnFail (après le dernier échec, suit la branche error si elle est connectée, sinon la première) \}. `timeout` au niveau de la définition : échéance globale de l'exécution ("2h"). human.approve accepte input.timeout ("2d") : sans décision, branche expired si elle est connectée, sinon échec. `concurrencyKey` au niveau de la définition : gabarit rendu au démarrage de l'exécution (par exemple "\{\{record.company_id\}\}") : au plus une exécution active par valeur de clé, les suivantes attendent leur tour (ordre de création), rien n'est abandonné. condition et switch lisent l'enregistrement (object, recordId, condition / field) ou, en mode valeur, n'importe quelle valeur de l'exécution : condition \{ left: "\{\{steps.x.output.y\}\}", op, right \}, switch \{ value: "\{\{steps.x.output.y\}\}", cases: [\{ id, label, op, value \}] \} (opérateurs de filtre : eq, neq, gt, in, contains, is_empty…). Variables d'entrée : \{\{record.…\}\}, \{\{event.…\}\} (\{\{event.recordId\}\} = enregistrement lié à l'événement déclencheur), \{\{steps.&lt;id&gt;.output.…\}\}, \{\{now\}\}, \{\{today\}\}, \{\{run.id\}\}, \{\{run.test\}\} (true dans une exécution de test), \{\{workflow.id\}\} (une variable inconnue est signalée par workflows.validate) ; dans loop.do : \{\{item\}\}, \{\{index\}\} et toutes les variables de l'exécution (blocs fn.\* et à entrée brute autorisés). Déclencheurs : trigger.schedule \{ cron, object? (sans object : une seule exécution), filter?, timezone? (IANA) \} ; trigger.run_failed \{ workflow? \} : workflow d'erreur démarré quand une exécution échoue (\{\{event.runId\}\}, \{\{event.workflowName\}\}, \{\{event.error\}\}). Sous-workflow : bloc workflow.run \{ workflow (id ou nom), recordId?, event?, wait (true par défaut : attend, branches ok/error, output = dernière sortie) \}, profondeur maximale 5. `pins` \{ stepId: \{ output, branch? \} \} : sorties épinglées rejouées par dry_run et test_step.

| `name`       | string | oui    |                                                                                    |
| `definition` | object | oui    |                                                                                    |
| `workspace`  | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## workflows.dry_run

Exécute une définition sans jamais rien écrire : écritures, envois, appels externes, boucles et fonctions ayant des permissions réseau ou 'write' sont simulés (première branche, sortie null) ; les lectures sont réelles. Les blocs d'IA (ai.\*) sont simulés par défaut, réels et facturés seulement avec ai: true. Une exécution par enregistrement de `records` ; sans enregistrements, une seule exécution sans enregistrement (utile pour un workflow déclenché par un événement ou un webhook) ; `event` = contenu de l'événement déclencheur (\{\{event.…\}\}). Les sorties épinglées (`definition.pins[stepId] = \{ output, branch? \}`) sont rejouées au lieu d'exécuter l'étape. Une étape `join: true` s'exécute une fois, après les autres chemins. Renvoie pour chaque exécution les chemins suivis (`paths`, un par branche d'exécution parallèle ; `path` : toutes les étapes à plat), avec pour chaque étape l'entrée, la sortie, la branche et la raison.

| Nom          | Type    | Requis | Description                                                                        |
| ------------ | ------- | ------ | ---------------------------------------------------------------------------------- |
| `definition` | object  | oui    |                                                                                    |
| `records`    | array   | non    | Identifiants d'enregistrements (facultatif)                                        |
| `event`      | any     | non    | Contenu de l'événement déclencheur                                                 |
| `ai`         | boolean | non    | true : exécute réellement les blocs d'IA (payant)                                  |
| `workspace`  | string  | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |
