## databases.create

Crée une base de données. Placez-y des objets avec objects.create (champ database).

| Nom           | Type   | Requis | Description                                                                        |
| ------------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `slug`        | string | oui    |                                                                                    |
| `name`        | string | oui    |                                                                                    |
| `icon`        | string | non    |                                                                                    |
| `description` | string | non    |                                                                                    |
| `workspace`   | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## databases.delete

Supprime une base de données. Refusé si elle contient des objets, sauf avec confirm=true : les objets et leurs enregistrements sont alors supprimés définitivement, en une seule transaction (tout ou rien). Exportez d'abord chaque objet (objects.export).

| Nom         | Type    | Requis | Description                                                                        |
| ----------- | ------- | ------ | ---------------------------------------------------------------------------------- |
| `database`  | string  | oui    | Slug de la base de données                                                         |
| `confirm`   | boolean | non    |                                                                                    |
| `workspace` | string  | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |
