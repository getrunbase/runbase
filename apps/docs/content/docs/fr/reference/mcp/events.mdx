## events.funnel

Entonnoir : nombre d'enregistrements distincts ayant reçu chaque type d'événement, dans l'ordre donné.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `types`     | array  | oui    |                                                                                    |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## events.list

Événements de l'espace de travail. Avec seulement `recordId` : chronologie de cet enregistrement (tableau). Sinon, filtres `type`, `recordId`, `from`/`to` (ISO, date de l'événement), du plus récent au plus ancien, paginés : renvoie \{ items, hasMore, nextCursor \} ; page suivante avec `cursor` = nextCursor.

| Nom         | Type    | Requis | Description                                                                        |
| ----------- | ------- | ------ | ---------------------------------------------------------------------------------- |
| `recordId`  | string  | non    |                                                                                    |
| `type`      | string  | non    |                                                                                    |
| `from`      | string  | non    |                                                                                    |
| `to`        | string  | non    |                                                                                    |
| `cursor`    | string  | non    |                                                                                    |
| `limit`     | integer | non    |                                                                                    |
| `workspace` | string  | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## events.push

Enregistre un événement, lié ou non à un enregistrement. `idempotencyKey` (identifiant externe) : un second envoi avec la même clé renvoie l'événement existant (`duplicate: true`) sans redéclencher les workflows. `test: true` : événement de test, supprimé par workspace.purge_test.

| Nom              | Type    | Requis | Description                                                                        |
| ---------------- | ------- | ------ | ---------------------------------------------------------------------------------- |
| `test`           | boolean | non    | Données de test : supprimées par workspace.purge_test                              |
| `type`           | string  | oui    |                                                                                    |
| `recordId`       | string  | non    |                                                                                    |
| `payload`        | object  | non    |                                                                                    |
| `occurredAt`     | string  | non    |                                                                                    |
| `source`         | string  | non    |                                                                                    |
| `idempotencyKey` | string  | non    |                                                                                    |
| `workspace`      | string  | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |
