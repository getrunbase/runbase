## api_keys.create

Crée une clé d'API (périmètre admin). La clé en clair n'est renvoyée qu'une seule fois. La clé ne voit que ses `workspaceIds`. Restrictions facultatives : `tools` (noms des outils MCP autorisés, par exemple ["records.search", "records.upsert"] ; les autres sont masqués) et `objects` (slugs des objets visibles : les autres objets et leurs enregistrements restent invisibles, query.sql indisponible). Absent = tout.

| Nom            | Type   | Requis | Description                                                                        |
| -------------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `name`         | string | oui    |                                                                                    |
| `scopes`       | array  | oui    |                                                                                    |
| `workspaceIds` | array  | oui    |                                                                                    |
| `tools`        | array  | non    |                                                                                    |
| `objects`      | array  | non    |                                                                                    |
| `workspace`    | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## api_keys.list
