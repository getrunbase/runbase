## records.delete

Met un enregistrement à la corbeille : il disparaît des lectures, des recherches et des requêtes SQL ; ses relations (ref/refs) sont retirées et sa chronologie conservée. Restaurable pendant 30 jours (records.restore), puis purgé.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `id`        | string | oui    |                                                                                    |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## records.search

Recherche les enregistrements d'un objet (filtre DSL all/any de \{ field, op, value \} ; opérateurs : eq, neq, gt, gte, lt, lte, between, in, not_in, contains, starts_with, ends_with, regex (sensible à la casse), before, after, within, older_than, is, is_empty, is_not_empty). `q` : texte libre (index trigramme). Renvoie \{ records, hasMore, total, next \}. Pagination : `after` = `next` de la page précédente (keyset, fonctionne avec n'importe quel tri). `view` : nom d'une vue enregistrée (son filtre est ajouté, son tri s'applique en l'absence de `sort`).
