## files.delete

Supprime un fichier téléversé par sa clé et libère ses octets dans l'usage de stockage de l'espace de travail. Retirez-le aussi du champ `file` de l'enregistrement.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `key`       | string | oui    |                                                                                    |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## files.download

Lit un fichier téléversé par sa clé (valeur d'un champ fichier) : renvoie \{ name, type, base64 \}.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `key`       | string | oui    |                                                                                    |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## files.upload

Téléverse un fichier (base64, 10 Mo maximum) et renvoie \{ key, name, size, type \} : placez-le dans le champ `file` d'un enregistrement (valeur = liste de ces objets).

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `name`      | string | oui    |                                                                                    |
| `type`      | string | non    | Type MIME                                                                          |
| `base64`    | string | oui    |                                                                                    |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |
