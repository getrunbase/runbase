## errors.get

Lit une erreur : référence, message, contenu (payload), pile d'appels.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `id`        | string | oui    | Identifiant de l'erreur                                                            |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## errors.list

Liste les erreurs de l'espace de travail (ingest, workflow, function = appel de fonction depuis une page, mcp = outil MCP en échec, component = composant de code en échec dans le navigateur d'un utilisateur ; payload \{page, block\}), de la plus récente à la plus ancienne. Filtres : source, statut, exécution, workflow, enregistrement, période (from/to ISO). Renvoie \{ items, hasMore, nextCursor \} : repassez nextCursor comme cursor pour obtenir la page suivante.

| Nom          | Type    | Requis | Description                                                                              |
| ------------ | ------- | ------ | ---------------------------------------------------------------------------------------- |
| `source`     | string  | non    | Valeurs possibles : `ingest`, `workflow`, `function`, `mcp`, `component`.                |
| `status`     | string  | non    | Valeurs possibles : `open`, `resolved`.                                                  |
| `runId`      | string  | non    |                                                                                          |
| `workflowId` | string  | non    |                                                                                          |
| `recordId`   | string  | non    |                                                                                          |
| `from`       | string  | non    |                                                                                          |
| `to`         | string  | non    |                                                                                          |
| `group`      | boolean | non    | Un élément par empreinte (même message normalisé) : le plus récent, avec count et lastAt |
| `cursor`     | string  | non    |                                                                                          |
| `limit`      | integer | non    | 50 par défaut                                                                            |
| `workspace`  | string  | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif)       |
