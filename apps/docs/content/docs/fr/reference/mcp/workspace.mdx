## workspace.describe

Tout l'espace de travail en un seul appel : bases de données &gt; objets (champs, nombre d'enregistrements), workflows (déclencheur, étapes, statut), fonctions (schémas, permissions, limites), webhooks, pages, noms des secrets, vues SQL lisibles par query.sql (nom, colonnes, types), compteurs (enregistrements, événements, exécutions actives, erreurs ouvertes). Appelez-le en premier pour découvrir un espace de travail.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## workspace.purge_test

Supprime les données de test (créées avec test: true) : enregistrements (corbeille puis purge, relations retirées), événements et exécutions terminées (une exécution encore active est conservée : runs.cancel d'abord). dryRun: true renvoie les compteurs sans rien supprimer ; sinon confirm: true requis. hasMore : rappelez pour le lot suivant.

| Nom         | Type    | Requis | Description                                                                        |
| ----------- | ------- | ------ | ---------------------------------------------------------------------------------- |
| `dryRun`    | boolean | non    |                                                                                    |
| `confirm`   | boolean | non    |                                                                                    |
| `workspace` | string  | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |
