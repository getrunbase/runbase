## webhooks.create

Crée un endpoint public POST /api/hooks/&lt;id&gt; (`path`) : signature vérifiée avec le secret `secretName` (secrets.set), puis événement `eventType` envoyé (déclencheur de workflow), dédupliqué par l'identifiant externe (`config.idPath`, `id` par défaut). `config.dedupe` : `id` (par défaut : un renvoi du même identifiant est ignoré, réponse duplicate: true, aucun workflow), `id+hash` (ignoré seulement si le contenu de l'élément est identique : un renvoi enrichi du même identifiant crée un nouvel événement et démarre le workflow), `none` (chaque appel crée un événement). Nom unique par espace de travail. Formats : `stripe`, `standard` (Standard Webhooks/Svix, id = en-tête webhook-id), `hmac` (header, algorithm sha256|sha1|sha512, encoding hex|base64, prefix par exemple `sha256=`, timestampHeader + gabarit `\{timestamp\}.\{body\}`, idHeader ; headerFormat `kv` lit une valeur d'en-tête `t=&lt;unix&gt;,v1=&lt;sig&gt;[,v1=…]` avec timestampKey (`t` par défaut) et signatureKey (`v1` par défaut, n'importe quelle signature listée convient), signedPayload `\{t\}.\{body\}` par défaut, toleranceSec 300 par défaut ; secretEncoding raw (par défaut) | base64 | whsec (`whsec_&lt;base64&gt;` décodé)). `stripe` = hmac kv sur `stripe-signature`. Façon Outreach : \{ format: 'hmac', header: 'X-Outreach-Signature', headerFormat: 'kv', signedPayload: '\{t\}.\{body\}' \}. Cal.com : hmac sur l'en-tête `x-cal-signature-256`. Lots : `config.splitPath` (par exemple `events`) ou un tableau racine donnent un événement par élément, `idPath` relatif à l'élément. `config.storeSample: false` : aucun exemple enregistré. URL de test `testPath` (/api/hooks/&lt;id&gt;/test) : signature vérifiée et exemple enregistré, aucun événement ni workflow démarré (pour écouter le prochain appel d'un fournisseur et écrire le mapping).

| `eventType`  | string | oui    |                                                                                    |
| `secretName` | string | oui    |                                                                                    |
| `config`     | object | oui    |                                                                                    |
| `workspace`  | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |
