## quotas.get

Limites et consommation de l'espace de travail : records (nombre maximal d'enregistrements), runsPerMinute (exécutions de workflows par minute), apiPerMinute (appels MCP et d'ingestion par minute), concurrency (étapes de workflows et événements déclencheurs traités en même temps ; les tâches en surplus attendent leur tour). Au-delà des trois premières, les appels échouent avec une erreur quota_exceeded (HTTP 429).

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## quotas.set

Définit les limites de l'espace de travail (périmètre admin). Une valeur omise revient à la valeur par défaut. Les valeurs sont plafonnées par les limites du compte (quotas.get : caps, null = illimité) : une valeur supérieure est refusée (quotas.exceedsLimit).

| Nom             | Type    | Requis | Description                                                                        |
| --------------- | ------- | ------ | ---------------------------------------------------------------------------------- |
| `records`       | integer | non    |                                                                                    |
| `runsPerMinute` | integer | non    |                                                                                    |
| `apiPerMinute`  | integer | non    |                                                                                    |
| `concurrency`   | integer | non    |                                                                                    |
| `workspace`     | string  | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |
