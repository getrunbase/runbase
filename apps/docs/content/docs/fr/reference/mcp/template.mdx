## template.export

Exporte l'espace de travail sous forme de runbase-template.json (format versionné) : bases de données, objets et schéma, vues enregistrées, fonctions, composants de code (TSX), workflows, pages, NOMS des secrets requis (jamais leurs valeurs) et enregistrements d'exemple facultatifs. Les identifiants de l'espace de travail sont remplacés par des références locales ($object:&lt;slug&gt;, $workflow:&lt;key&gt;, $record:&lt;key&gt;). Renvoie le JSON du modèle.

| Nom             | Type    | Requis | Description                                                                        |
| --------------- | ------- | ------ | ---------------------------------------------------------------------------------- |
| `name`          | string  | non    |                                                                                    |
| `description`   | string  | non    |                                                                                    |
| `sampleRecords` | integer | non    | enregistrements d'exemple par objet (0 par défaut)                                 |
| `workspace`     | string  | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## template.import

Importe un runbase-template.json dans l'espace de travail (périmètre admin) : crée bases de données, objets, vues, enregistrements, fonctions, workflows (en brouillon), composants et pages. Refusé si un objet, une fonction ou un composant du même nom existe. Modèle invalide : une erreur par problème avec son chemin. Renvoie les compteurs, les identifiants des workflows et pages créés, et missingSecrets à définir (secrets.set) avant d'activer les workflows.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `template`  | union  | oui    | l'objet du modèle, ou son texte JSON                                               |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |
