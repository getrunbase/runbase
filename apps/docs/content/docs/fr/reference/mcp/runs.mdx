## runs.cancel

Annule une exécution non terminée (statut canceled) : ses étapes s'arrêtent et l'enregistrement peut relancer une exécution. false si elle est déjà terminée.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `id`        | string | oui    | Identifiant de l'exécution                                                         |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## runs.cancel_bulk

Annule toutes les exécutions non terminées d'un workflow et/ou d'un statut (au moins un filtre). confirm: true requis. Renvoie le nombre d'exécutions annulées.

| Nom          | Type    | Requis | Description                                                                        |
| ------------ | ------- | ------ | ---------------------------------------------------------------------------------- |
| `workflowId` | string  | non    |                                                                                    |
| `status`     | string  | non    | Valeurs possibles : `running`, `waiting`, `paused_budget`, `paused`.               |
| `confirm`    | boolean | non    |                                                                                    |
| `workspace`  | string  | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## runs.decide

Approuve ou rejette une exécution en pause (human.approve) : elle reprend sur la branche approuvée ou rejetée. Erreur not_found (exécution inconnue) ou not_waiting (exécution ou chemin pas en attente, avec la raison).

| Nom         | Type    | Requis | Description                                                                        |
| ----------- | ------- | ------ | ---------------------------------------------------------------------------------- |
| `id`        | string  | oui    | Identifiant de l'exécution                                                         |
| `approved`  | boolean | oui    |                                                                                    |
| `path`      | string  | non    | Chemin en attente à trancher (par défaut : le premier)                             |
| `workspace` | string  | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## runs.get

Lit une exécution et ses étapes : chemin suivi (branche ; `path` = branche d'exécution parallèle, "0", "1", "0.1"…), entrée, sortie (raisonnements de l'IA compris ; boucle : détail par itération), journaux des fonctions fn.\* (`logs`), startedAt, tentatives, durée, coût, erreur. `paths` donne l'état de chaque chemin.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `id`        | string | oui    | Identifiant de l'exécution                                                         |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## runs.list

Liste les exécutions de l'espace de travail, de la plus récente à la plus ancienne, avec leur coût. Filtres : statut, workflow, enregistrement, période (from/to ISO). Renvoie \{ items, hasMore, nextCursor \} : repassez nextCursor comme cursor pour obtenir la page suivante.

| Nom          | Type    | Requis | Description                                                                                             |
| ------------ | ------- | ------ | ------------------------------------------------------------------------------------------------------- |
| `status`     | string  | non    | Valeurs possibles : `running`, `waiting`, `succeeded`, `failed`, `paused_budget`, `paused`, `canceled`. |
| `workflowId` | string  | non    |                                                                                                         |
| `recordId`   | string  | non    |                                                                                                         |
| `from`       | string  | non    |                                                                                                         |
| `to`         | string  | non    |                                                                                                         |
| `cursor`     | string  | non    |                                                                                                         |
| `limit`      | integer | non    | 50 par défaut                                                                                           |
| `workspace`  | string  | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif)                      |

## runs.pause

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `id`        | string | oui    | Identifiant de l'exécution                                                         |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## runs.retry_from

Relance une exécution terminée (réussie, échouée ou annulée) à partir d'une étape : cette étape et la suite de son chemin sont effacées et réexécutées, les étapes antérieures sont conservées. Refusé si une autre exécution est active sur le même enregistrement.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `id`        | string | oui    | Identifiant de l'exécution                                                         |
| `stepId`    | string | oui    | Identifiant de l'étape à partir de laquelle reprendre                              |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |

## runs.start

Démarre une exécution de la version courante d'un workflow, sur un enregistrement facultatif, avec un contenu d'événement facultatif (`event`, lu par \{\{event.…\}\} comme si l'événement avait déclenché l'exécution). Refusé si une exécution du même workflow est déjà active sur cet enregistrement. `test: true` : exécution de test, supprimée par workspace.purge_test.

| Nom         | Type    | Requis | Description                                                                        |
| ----------- | ------- | ------ | ---------------------------------------------------------------------------------- |
| `id`        | string  | oui    | Identifiant du workflow                                                            |
| `recordId`  | string  | non    |                                                                                    |
| `event`     | any     | non    |                                                                                    |
| `test`      | boolean | non    | Données de test : supprimées par workspace.purge_test                              |
| `workspace` | string  | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |
