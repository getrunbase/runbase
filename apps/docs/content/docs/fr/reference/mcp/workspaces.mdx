## workspaces.set_ai_budget

Définit le budget IA mensuel en USD (null = illimité). À 100 %, les blocs d'IA sont bloqués et les exécutions passent en paused_budget ; elles reprennent si le budget est relevé. Plafonné par la limite du compte (quota:aiBudgetUsd) : une valeur supérieure est refusée. Il n'existe ni clé d'IA de la plateforme ni IA par défaut de l'espace de travail : chaque bloc d'IA (`ai` dans son entrée) et chaque page (`permissions.ai`) indique son fournisseur, son modèle et le secret de sa clé.

| Nom         | Type   | Requis | Description                                                                        |
| ----------- | ------ | ------ | ---------------------------------------------------------------------------------- |
| `budgetUsd` | union  | oui    |                                                                                    |
| `workspace` | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |
