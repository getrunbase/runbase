## page.create

Crée une page à partir d'un paquet TSX (brouillon ; `publish: true` publie immédiatement). Les composants partagés sont des fichiers du paquet (par exemple components/card.tsx).

| Nom           | Type    | Requis | Description                                                                                                                                                                                                                                                        |
| ------------- | ------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `name`        | string  | oui    |                                                                                                                                                                                                                                                                    |
| `icon`        | string  | non    | Icône Lucide de la page dans la navigation (kebab-case, par exemple users, shopping-cart, kanban, chart-line ; voir lucide.dev/icons). Choisissez l'icône la plus adaptée au contenu de la page. Par défaut : layout-dashboard.                                    |
| `files`       | object  | oui    | Paquet TSX : \{"&lt;chemin relatif&gt;": "&lt;source&gt;"\}, par exemple \{"index.tsx": "export default function Page() \{…\}", "components/card.tsx": "…"\}. Les chemins sont relatifs (pas de "..", pas de "/" initial) ; le fichier d'entrée doit être présent. |
| `entry`       | string  | non    | fichier d'entrée du paquet (index.tsx par défaut)                                                                                                                                                                                                                  |
| `deps`        | object  | non    |                                                                                                                                                                                                                                                                    |
| `permissions` | object  | non    | Permissions SDK déclarées par la page                                                                                                                                                                                                                              |
| `publish`     | boolean | non    |                                                                                                                                                                                                                                                                    |
| `workspace`   | string  | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif)                                                                                                                                                                                 |

## page.errors

Erreurs d'exécution récentes d'une page dans le navigateur (erreurs non interceptées, promesses rejetées non gérées, erreurs de rendu React, console.error), remontées par l'iframe de la page en quelques secondes : la version publiée, ou le brouillon avec `draft: true`. Chaque erreur comporte message, emplacement (file:line:col dans la source du paquet), pile d'appels, count (dédupliqué) et lastSeen ; les erreurs expirent après 24 h. Ouvrez d'abord la page (page.screenshot) pour les collecter.

## page.screenshot

Capture d'écran PNG d'une page enregistrée telle que la voit un utilisateur (vraies données de l'espace de travail, composants de code compris), en lecture seule : les actions et les workflows ne sont pas exécutés. `draft: true` capture le brouillon (après page.update, avant page.publish). Attend que chaque composant de code ait fini son rendu et que les chargements (squelettes) aient disparu (8 s maximum). Compte utilisateur (OAuth) ou clé d'API. Renvoie l'image puis \{errors, console\} ; errors inclut les erreurs des composants de code (aussi enregistrées dans errors.list, source component). À utiliser après page.create/update pour vérifier le rendu (ordinateur et mobile).

| ---------------- | ------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| `draft`          | boolean | non    | capturer le brouillon                                                                                                                                                                                |
| `params`         | object  | non    | Paramètres d'URL, par exemple \{"id": "&lt;recordId&gt;"\}                                                                                                                                           |
| `componentState` | object  | non    | État useParam des blocs de code : \{&lt;blockId&gt;: \{&lt;key&gt;: value\}\} (identique aux paramètres d'URL c.&lt;blockId&gt;.&lt;key&gt;=&lt;JSON&gt;), par exemple \{"app": \{"tab": "deals"\}\} |

## page.update

Met à jour une page. Le nom et l'icône s'appliquent immédiatement. `changes` est un correctif de fichiers appliqué dans l'ordre au brouillon, tout ou rien : \{op: write, path, source\} crée ou remplace un fichier, \{op: edit, path, old, new\} remplace un texte présent une seule fois, \{op: rename, from, to\} (l'entrée suit), \{op: delete, path\} (pas l'entrée). `files` remplace tout le paquet. Les modifications du brouillon restent invisibles pour les utilisateurs jusqu'à page.publish (`publish: true` publie immédiatement). Le paquet est recompilé : renvoie \{page, errors\} (erreurs de compilation, file:line), puis, sauf `review: false` ou erreurs de compilation, `review` = \{a11y (violations axe), pageErrors (erreurs d'exécution), renderErrors, warnings\} suivi des captures ordinateur et mobile du brouillon.

| Nom           | Type    | Requis | Description                                                                                                                                                                                                                                                        |
| ------------- | ------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `id`          | string  | oui    | Identifiant de la page                                                                                                                                                                                                                                             |
| `name`        | string  | non    |                                                                                                                                                                                                                                                                    |
| `icon`        | string  | non    | Icône Lucide de la page dans la navigation (kebab-case, par exemple users, shopping-cart, kanban, chart-line ; voir lucide.dev/icons). Choisissez l'icône la plus adaptée au contenu de la page. Par défaut : layout-dashboard.                                    |
| `changes`     | array   | non    |                                                                                                                                                                                                                                                                    |
| `files`       | object  | non    | Paquet TSX : \{"&lt;chemin relatif&gt;": "&lt;source&gt;"\}, par exemple \{"index.tsx": "export default function Page() \{…\}", "components/card.tsx": "…"\}. Les chemins sont relatifs (pas de "..", pas de "/" initial) ; le fichier d'entrée doit être présent. |
| `entry`       | string  | non    | fichier d'entrée du paquet (index.tsx par défaut)                                                                                                                                                                                                                  |
| `deps`        | object  | non    |                                                                                                                                                                                                                                                                    |
| `permissions` | object  | non    | Permissions SDK déclarées par la page                                                                                                                                                                                                                              |
| `publish`     | boolean | non    |                                                                                                                                                                                                                                                                    |
| `review`      | boolean | non    | revue automatique du brouillon (true par défaut, ignorée en cas d'erreurs de compilation) : captures ordinateur et mobile, violations axe-core et erreurs d'exécution                                                                                              |
| `workspace`   | string  | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif)                                                                                                                                                                                 |
