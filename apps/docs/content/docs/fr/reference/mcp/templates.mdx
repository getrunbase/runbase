## templates.submit

Soumet un modèle au catalogue public de Runbase. Validation automatique d'abord : description d'au moins 300 mots avec les sections ## Who it's for, ## The problem, ## What it does, ## Setup ; manifeste runbase-template.json valide (obtenez-le avec template.export) ; profil d'auteur (passez `author` pour un premier modèle). Refusé : une erreur claire par problème. Accepté : ouvre une pull request pour une relecture humaine et renvoie son URL ; le modèle est publié à la fusion. Aucun paiement en jeu.

| Nom              | Type   | Requis | Description                                                                                                 |
| ---------------- | ------ | ------ | ----------------------------------------------------------------------------------------------------------- |
| `slug`           | string | oui    | Slug du modèle (nom du dossier), par exemple crm-light                                                      |
| `name`           | string | oui    |                                                                                                             |
| `categories`     | array  | oui    |                                                                                                             |
| `githubUsername` | string | oui    | Identifiant GitHub du créateur (authorId)                                                                   |
| `description`    | string | oui    | Markdown, au moins 300 mots, avec les sections : ## Who it's for, ## The problem, ## What it does, ## Setup |
| `manifest`       | object | oui    | Le manifeste runbase-template.json (template.export)                                                        |
| `author`         | object | non    | Profil du créateur, requis pour un premier modèle                                                           |
| `workspace`      | string | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif)                          |
