## audit.list

Journal d'audit de l'espace de travail (qui, quoi, quand), du plus récent au plus ancien (périmètre admin). Sans filtre : tout le flux. Filtres : `type` et `id` (une ressource : enregistrement, workflow, fonction…), `action` (exacte, ou préfixe terminé par un point : `record.`), `actorUserId`, `actorApiKeyId`, `from`/`to` (ISO). Renvoie \{ items, hasMore, nextCursor \} ; page suivante avec `cursor` = nextCursor.

| --------------- | ------- | ------ | ---------------------------------------------------------------------------------- |
| `type`          | string  | non    |                                                                                    |
| `id`            | string  | non    |                                                                                    |
| `action`        | string  | non    |                                                                                    |
| `actorUserId`   | string  | non    |                                                                                    |
| `actorApiKeyId` | string  | non    |                                                                                    |
| `from`          | string  | non    |                                                                                    |
| `to`            | string  | non    |                                                                                    |
| `cursor`        | string  | non    |                                                                                    |
| `limit`         | integer | non    |                                                                                    |
| `workspace`     | string  | non    | Identifiant ou nom de l'espace de travail (par défaut : l'espace de travail actif) |
