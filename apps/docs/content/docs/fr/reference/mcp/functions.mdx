## functions.create

Crée une fonction TypeScript (périmètre admin), refusé si le nom existe déjà. Elle est ensuite utilisable comme bloc fn.&lt;name&gt;. Code : `export default async (input, \{ records, events, secrets, test \}) =&gt; output`. Convention d'échec dans un workflow (étape fn._) : renvoyez `\{ ok: false, error: "message" \}` ou levez une exception : l'étape échoue, est relancée selon sa politique de nouvelles tentatives, puis l'exécution échoue et l'erreur apparaît dans errors.list. `test` : true dans une exécution de test (runs.start \{ test: true \}, ou une exécution qui en hérite) ; les enregistrements et événements écrits par la fonction dans une exécution de test sont automatiquement marqués comme test. Secrets déclarés : clé de contexte `secrets` (et input.secrets si l'entrée n'a pas déjà ce champ). SDK records (permissions.records 'read' : get, search ; 'write' : + upsert, update, transact, delete, merge) : `await records.get(id)`, `records.search(object, \{filter, limit\})` (object = slug ou uuid), `records.upsert(\{objectId: slug or uuid, data, match\})` (renvoie \{record, created\}), `records.update(id, data)`, `records.transact(ops)`, `records.delete(id)` (corbeille), `records.merge(keepId, [ids])` ; aussi disponible en global `records`. SDK events (permissions.events 'read' : `events.list(\{type, recordId, from, to, cursor, limit\})` ; 'write' : + `events.push(\{type, recordId, payload, occurredAt, idempotencyKey\})`). `permissions.domains` : noms d'hôtes ou `'_'`= tout l'internet public (périmètre admin) ; les IP privées, de bouclage, link-local et de métadonnées cloud (RFC1918, 127/8, ::1, 169.254/16, 100.64/10, fc00::/7) sont bloquées après résolution DNS et lors des redirections. HTML :`parseHTML(html)`renvoie`\{ document \}`(linkedom : querySelectorAll, textContent, getAttribute) et`new DOMParser().parseFromString(html, 'text/html')`, en globals et via `ctx.parseHTML`; pas de rendu navigateur, pas d'import npm.`limits` : \{ timeoutMs 1000-120000 (30000 par défaut), memoryMb 32-512 (128 par défaut) \}. console.\* = journaux (64 Ko maximum), visibles dans functions.test, functions.logs et runs.get.

## functions.test

Exécute réellement une fonction, hors de tout workflow : renvoie la sortie et les journaux. | `dryRun`    | boolean | non    |                                                                                    |
