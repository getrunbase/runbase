---
title: Démarrage rapide
description: Lancez Runbase en local, connectez un agent IA via MCP et construisez un petit CRM.
---

## 1. Lancer une instance

Il vous faut Docker avec le plugin Compose, ainsi que `openssl`.

```sh
git clone https://github.com/getrunbase/runbase runbase && cd runbase
./setup.sh
docker compose -f docker-compose.selfhost.yml up -d --wait
docker compose -f docker-compose.selfhost.yml exec worker pnpm admin:create you@example.com
```

Ouvrez `http://localhost:3000/login` et demandez un lien de connexion. Sans
configuration e-mail, le lien s'affiche dans les logs du service web :

```sh
docker compose -f docker-compose.selfhost.yml logs web | grep email:console
```

Consultez la page [auto-hébergement](/docs/self-hosting) pour HTTPS, les
sauvegardes et les mises à jour.

## 2. Connecter un agent

Le point de terminaison MCP est `http://localhost:3000/api/mcp`. Les clients se connectent via le
navigateur (OAuth). Choisissez le vôtre :

- **Claude Code** : `claude mcp add --transport http runbase http://localhost:3000/api/mcp`, puis
  `/mcp` dans Claude Code pour se connecter.
- **Claude Desktop / claude.ai** : Paramètres → Connecteurs → Ajouter un
  connecteur personnalisé, collez l'URL.
- **ChatGPT** (web) : chatgpt.com/plugins → **+** → **Add custom MCP server**,
  collez l'URL, choisissez OAuth, acceptez l'avertissement, **Create as a
  plugin**. Tapez `@` dans une conversation pour l'utiliser. Les outils
  d'écriture demandent une offre Business ou Enterprise/Edu (Pro : lecture
  seule).
- **Gemini CLI** : `gemini mcp add --transport http runbase http://localhost:3000/api/mcp`, puis
  `/mcp auth runbase`. L'application web Gemini (Paramètres → Applications
  connectées → Ajouter une application personnalisée) a une disponibilité
  limitée.
- **Cursor** : ajoutez `{"mcpServers":{"runbase":{"url":"http://localhost:3000/api/mcp"}}}` à
  `~/.cursor/mcp.json`. Cursor demande de se connecter à la première
  utilisation.
- **Codex** : `codex mcp add runbase --url http://localhost:3000/api/mcp`, puis
  `codex mcp login runbase`.
- **Autres clients MCP** : utilisez l'URL (Streamable HTTP, OAuth), ou créez
  une clé d'API dans **Settings → API keys** et envoyez-la sous la forme
  `Authorization: Bearer <key>`.

## 3. Construire quelque chose

Demandez par exemple à l'agent :

> Construis un petit CRM : des entreprises et des contacts, un score de lead,
> un workflow qui note les nouveaux contacts et une page de pipeline.

L'agent appelle généralement `workspace.describe`, puis `databases.create`,
`objects.create`, `records.upsert_batch` (avec `test: true` pour les données
d'exemple), `workflows.create` et `page.create`. Tous les outils sont listés
dans la [référence MCP](/docs/reference/mcp).

## 4. Nettoyer les données de test

`workspace.purge_test` avec `{ "dryRun": true }`, puis `{ "confirm": true }`,
supprime les enregistrements, événements et exécutions de test.
