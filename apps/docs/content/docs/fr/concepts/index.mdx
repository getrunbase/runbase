---
title: Concepts
description: Les briques de base de Runbase et la façon dont elles s'articulent.
---

| Concept | Description |
| --- | --- |
| [Espaces de travail](/docs/concepts/workspaces) | Espaces isolés au sein d'une organisation. Illimités et gratuits. |
| [Données](/docs/concepts/data) | Bases de données, objets (schémas typés) et enregistrements. |
| [Événements](/docs/concepts/events) | Faits horodatés, rattachés ou non à un enregistrement. |
| [Webhooks](/docs/concepts/webhooks) | URL publiques qui transforment les appels entrants en événements et en enregistrements. |
| [Fonctions](/docs/concepts/functions) | Code JavaScript versionné, exécuté dans un bac à sable. |
| [Workflows](/docs/concepts/workflows) | Des déclencheurs et un graphe de nœuds, exécutés de façon durable. |
| [Interfaces](/docs/concepts/interfaces) | Pages, tableaux de bord et composants de code. |
