---
title: Introduction
description: Runbase permet à votre agent IA de construire et de faire tourner les outils que votre équipe loue aujourd'hui, en open source et auto-hébergeable.
---

Arrêtez de louer des outils qui font presque ce qu'il faut. Avec Runbase, votre
agent construit le CRM, le workflow ou le dashboard dont vous avez besoin et le
fait tourner : données typées, événements, webhooks entrants,
fonctions isolées dans un bac à sable, workflows et interfaces. N'importe quel agent le pilote
via [MCP](/docs/reference/mcp) ; les utilisateurs passent par l'application
web ; les programmes, par l'[API REST](/docs/reference/api). Chaque changement est
validé et versionné avant d'être activé, et vous pouvez l'auto-héberger ou partir
quand vous voulez.

- Vous découvrez Runbase ? Commencez par le [démarrage rapide](/docs/quickstart).
- Vous hébergez votre propre instance ? Lisez la page [auto-hébergement](/docs/self-hosting).
- Vous voulez comprendre le modèle ? Lisez les [concepts](/docs/concepts).
- Vous étendez Runbase ? Consultez [écrire un connecteur](/docs/guides/connectors)
  et le [format des templates](/docs/guides/templates).
