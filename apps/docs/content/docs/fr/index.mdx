---
title: Introduction
description: Runbase est une plateforme de données, d'automatisation et d'interfaces sur laquelle s'appuient les agents IA.
---

Runbase fournit à un agent IA tout ce qu'il faut pour construire un outil
métier de bout en bout : données typées, événements, webhooks entrants,
fonctions isolées dans un bac à sable, workflows et interfaces. L'agent le pilote
via [MCP](/docs/reference/mcp) ; les utilisateurs passent par l'application
web ; les programmes, par l'[API REST](/docs/reference/api).

- Vous découvrez Runbase ? Commencez par le [démarrage rapide](/docs/quickstart).
- Vous hébergez votre propre instance ? Lisez la page [auto-hébergement](/docs/self-hosting).
- Vous voulez comprendre le modèle ? Lisez les [concepts](/docs/concepts).
- Vous étendez Runbase ? Consultez [écrire un connecteur](/docs/guides/connectors)
  et le [format des templates](/docs/guides/templates).
